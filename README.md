# Cvetna bašta (PDKI 2026)

Prototip korisničkog interfejsa digitalne prodavnice biljaka.
Vue 3 + Vite + TypeScript + Bootstrap 5 + SweetAlert2, u strukturi projekta sa vežbi.

Pokretanje: `npm install`, pa `npm run dev`. Detalje (PDF, predaja) vidi u `UPUTSTVO.md`.
Demo nalog: demo@cvetnabasta.rs / demo12345
